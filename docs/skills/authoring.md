# Authoring

Read the [current guide](https://github.com/TinyWarden/tinywarden/blob/main/docs/build-skills/README.md).

To add an item to the app's individual/bulk Fleet picker, follow
[Add items to Fleet Skill actions](https://github.com/TinyWarden/tinywarden/blob/main/docs/build-skills/actions.md#add-items-to-fleet-skill-actions).
The package's existing action declarations supply names/help and behavior. The app
groups available, explicitly permitted actions by their owning skill. Compatible
actions use the existing SDK/API without changes to the host agent.
