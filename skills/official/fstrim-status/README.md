# Filesystem trim

Observes fstrim.timer and its service result. Successful completion evidence survives a server reboot, and a weekly schedule is assessed against its expected run rather than the age of every reading. It does not prove that device space was physically reclaimed.

Python SDK v1. Verified support: Debian 13 on amd64. No maintenance action is performed.
Settings and individual server inheritance are supplied by the TinyWarden engine.
